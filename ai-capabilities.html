AI 能力接口说明

以 MCP 工具为单位，明确任务、目标、计划、简报四个模块的能力范围。采用本轮已确认清单，不把字段参数和使用场景拆成独立能力。

版本 v1.02026-10-094 个模块 · 49 项能力

任务模块4 项

接口沿用创建、查询、修改、删除四类。拆解、分配、排期和整理作为调用场景，不另设接口。

能力MCP 工具名称用途与范围
创建任务create_tasks根据描述、便签或资料创建一个或多个任务；拆解任务后也使用此接口。
查询任务query_tasks查询列表或详情，按人员、日期、状态、计划和分组筛选。
修改任务update_tasks修改内容、人员、日期、状态和归属；整理、分配与排期通过此接口完成。
删除任务delete_tasks删除指定任务或批量删除任务。

目标模块13 项

草稿不可发起。周转箱是系统分组，不支持改名、删除、重排或创建子分组。确认和审批流程只查询、选择系统预设，不开放自定义流程。

能力MCP 工具名称用途与范围
创建目标create_goals创建目标模板或草稿，并填写负责人员、分组与 KR。
查询目标query_goals查询模板、草稿、组织或个人执行目标，支持周期、人员、分组与阶段筛选。
修改目标update_goals修改目标属性、KR、当前完成值、预设流程、阶段与分组，支持批量操作。
删除目标delete_goals删除草稿、模板或执行目标，支持批量删除。
排序目标reorder_goals调整一个或多个目标在列表中的自定义顺序。
发起目标launch_goals选择模板与周期，为模板配置的成员生成独立执行目标，进入确认中。
催办目标remind_goals催办已选目标或当前筛选范围内的执行目标。
查询目标流程query_goal_workflows查询系统预设的确认流程和审批流程。
查询目标沟通query_goal_comments读取目标中的讨论与评论。
创建目标分组create_goal_groups创建最外层分组或已有分组下的子分组。
查询目标分组query_goal_groups查询分组树、上下级关系、名称和完整路径。
修改目标分组update_goal_groups重命名、排序或移动分组，调整上下级关系。
删除目标分组delete_goal_groups删除分组及子分组，关联目标保留并转入周转箱。

计划模块18 项

计划分组是列表左侧的外层分类，计划内分组是进入计划后的任务分组。外层分组与目标模块共用；从目标创建后，计划与目标互不自动同步。

能力MCP 工具名称用途与范围
创建计划create_plans空白创建计划，或从目标快照创建计划并按 KR 生成计划内分组。
查询计划query_plans查询计划列表、详情、状态、来源目标、分组及任务。
修改计划update_plans修改标题、描述、负责人、协助人员和归属；完成或重新开启计划。
删除计划delete_plans删除计划及其内部的分组、任务，支持批量删除。
排序计划reorder_plans调整一个或多个计划的自定义顺序。
查询计划沟通query_plan_comments读取计划或计划任务中的评论。
创建计划分组create_plan_directories创建计划列表左侧的外层分组或子分组。
查询计划分组query_plan_directories查询外层分组树、名称和上下级关系。
修改计划分组update_plan_directories重命名、排序或移动外层分组。
删除计划分组delete_plan_directories删除外层分组及子分组，关联计划保留为未归类。
创建计划内分组create_plan_groups在指定计划内创建用于容纳任务的分组。
查询计划内分组query_plan_groups查询指定计划内的分组及其负责人、顺序。
修改计划内分组update_plan_groups修改分组名称、负责人和排序。
删除计划内分组delete_plan_groups删除计划内分组及其中的任务。
创建计划任务create_plan_tasks在计划内分组中创建任务，填写人员、日期和内容。
查询计划任务query_plan_tasks查询计划任务详情及按人员、日期、状态和分组筛选的列表。
修改计划任务update_plan_tasks修改任务属性、执行状态、分组及顺序。
删除计划任务delete_plan_tasks删除指定计划任务。

简报模块14 项

不提供独立的草稿填写或附件上传能力；上传附件与正式提交由 submit_brief 统一组织。审阅通过、退回共用 review_brief。

能力MCP 工具名称用途与范围
创建简报create_briefs创建简报，配置基本信息、表单模板与规则。
查询简报query_briefs查询简报配置、填写内容、成员提交记录及审阅状态。
修改简报配置update_briefs修改基本信息、表单模板、提交规则、提醒、审阅设置和所属分组。
删除简报delete_briefs删除指定简报及其相关提交记录。
提交简报submit_brief填写并提交简报，包含附件上传和关联目标、任务等表单内容。
撤回简报withdraw_brief按业务规则撤回当前用户已提交的简报。
审阅简报review_brief通过或退回成员提交的简报，并填写评分与审阅意见。
撤销简报审阅undo_brief_review按业务规则撤销已完成的审阅。
催办简报remind_briefs催办尚未提交简报的成员。
查询简报沟通query_brief_comments读取简报中的讨论与评论。
创建简报分组create_brief_groups创建简报分组或子分组。
查询简报分组query_brief_groups查询简报分组树与上下级关系。
修改简报分组update_brief_groups重命名、移动或排序简报分组。
删除简报分组delete_brief_groups删除简报分组及子分组，同时删除组内简报和提交记录。

开发约定

  • 表中名称为拟定的 MCP 工具名称，不表示当前已有同名接口。开发可复用、组合现有 HTTP 接口实现。
  • 创建与修改通过参数设置人员、日期、状态和归属；不新增独立的分配、排期、拆解或整理工具。
  • 查询返回真实数据；写操作返回实际成功结果与对象 ID。批量操作需明确成功、失败及原因。
  • 计划任务与任务模块共用数据，优先复用同一套任务工具实现，避免形成两套业务规则。
  • “计划分组”的英文名称保留 directories，用于区分计划内 groups；中文统一使用分组。目标和计划的外层分组共用结构。
  • 附件上传可作为 submit_brief 的内部步骤；任一步失败，不应返回简报提交成功。
  • 遵守操作人的数据权限和业务状态限制。本文不新增审批、恢复删除、外部消息等未确认的能力。

现有实现需补齐

  • 目标：催办、个人待办和目标沟通尚未形成完整后端链路；本清单不包含目标待办处理能力。
  • 目标新建：“添加目标模版”当前保存 is_template=false，与目标库筛选不一致，接入前需修正。
  • 目标与计划分组：删除树节点与搬迁关联数据的流程尚未完整接通，需统一完成后再返回成功。
  • 目标：多成员配置仍有浏览器本地存储和默认模拟分配；需落到服务端，才能可靠地由 MCP 查询、修改和发起。
  • KR 数据源目前仅为选项配置，不代表监控、BI 或 GitHub 已接通。
  • 简报：催办与沟通尚未接通真实通知及持久化链路。只实现界面提示不算能力完成。

以上基于当前项目源码核对；本文是开发范围说明，不是上线验收报告。
